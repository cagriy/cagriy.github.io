## Code Examples

### T-SQL

```sql
SELECT This, [Is], A, Code, Block
    , REVERSE('abc')
FROM dbo.SomeTable s
    CROSS JOIN dbo.OtherTable o;
```

### PowerShell

```powershell
Write-Host "This is a PowerShell code block"

ForEach ($thing in $things) {
    Write-Output "It highlights using the default style"
}
```
